# Mr Sayrws

Reverse engineer and malware analyst. I take binaries apart — unpacking
malware, tracing C2 traffic, building exploits for CTF challenges — and
document what I find on [YouTube](https://www.youtube.com/@mrsayrws) and in my
[writing](https://mrsayrws.github.io/blog/).

- **Focus** — malware analysis, binary exploitation, digital forensics
- **Toolkit** — Ghidra, IDA Pro, x64dbg, Wireshark, Volatility
- **Also** — C/C++, C#/.NET, Python, PowerShell, Bash
